# Graduation Documents Checklist

README สำหรับเช็กลิสต์เอกสารที่ต้องใช้ในการส่งจบการศึกษา ตามความเข้าใจของผมเอง
เพื่อเป็น แนวทางเบื้องต้นกับเพื่อนๆ เช็คความถูกต้องเพิ่มเติมจาก คณะนะครับ

---

## 1. ส่งเล่มพี่แวว

- [ ] ตรวจ Turnitin ผ่านที่ <= 20%
- [ ] เล่มฉบับ Word / PDF
- [ ] แจ้งพี่แววว่าเลือกส่งงาาน Option 1, 2 หรือ 3
- [ ] แนบ Slip Option 1, 2 หรือ 3

---

## 2. IRB

### 2.2 กรอก Forms ตามเงื่อนไขของตัวเอง

> 
> เช่นของผมเงื่อนไขแรก เตรียมเอกสารดังนี้

  > **Advisor’s signature required.**
- [ ] แบบฟอร์มประวัติผู้วิจัย
- [ ] แบบฟอร์มการประเมินตนเองโดยผู้วิจัย  
  > Self-Assessment Form PI

- [ ] เอกสารอนุมัติโครงร่างวิทยานิพนธ์
